# Northstar Design System

- Keep our existing restrained, text-first product language. Use system-ui typography; do not add a webfont.
- Use the existing CSS custom properties: `--color-text`, `--color-background`, `--color-accent`, `--color-danger`, `--space-2`, and `--space-4`.
- Keep surfaces flat. Do not add gradients, shadows, decorative cards, or entrance animations.
- Primary action text describes the result, e.g. "Save email address".
- Forms are single-column and must fit a 320px viewport without horizontal scrolling.
